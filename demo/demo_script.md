DataMind Manufacturing — Demo Script

1. Introduction

DataMind Manufacturing is an AI-powered conversational data analysis system designed to help manufacturing managers understand factory operations using natural-language questions.

The system uses Google Gemma to interpret questions and Snowflake to retrieve manufacturing data.

2. Demo: Production Analysis

Question: What is the total production?

Expected demonstration:

- Enter the question in the application.
- Show the generated SQL query.
- Display the result retrieved from Snowflake.
- Explain the result using supporting evidence.

3. Demo: Machine Downtime

Question: Which machine has the highest downtime?

Expected demonstration:

- Identify the machine with the highest downtime.
- Display the relevant database result.
- Verify that the answer matches the data.

4. Demo: Inventory

Question: Which raw material has the lowest stock?

Expected demonstration:

- Display the material with the lowest stock.
- Show the supporting records.

5. Demo: Error Handling

Question: What is the weather today?

Expected demonstration:
The system should explain that this question is outside the supported manufacturing-data scope.

6. Conclusion

DataMind Manufacturing aims to make manufacturing data easier to access through conversational queries and evidence-backed answers.

Note: Perform the demonstration only after the integrated application is working. Use actual database results rather than invented values.
