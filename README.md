DataMind Manufacturing

Project Overview

DataMind Manufacturing is an AI-powered conversational data analysis system that helps manufacturing managers understand factory operations using natural-language questions.

The system uses Google Gemma to interpret questions and Snowflake to retrieve manufacturing data.

Technologies

- Python
- Google Gemma
- Snowflake
- Streamlit
- Git and GitHub
